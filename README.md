# 🛠️ Featured Projects

### 🔹 Low-Code Dynamic Form Builder

A full-stack platform for creating and managing dynamic forms without writing code.

**Highlights:**

* Dynamic form builder with multiple field types
* Conditional logic and dynamic validation
* Multilingual form support
* JWT authentication and role-based access
* File uploads
* Form versioning and publishing
* Response collection with idempotency support
* Analytics dashboard and visualizations
* CSV/JSON response export
* Response filtering and search
* Data retention and audit logging

**Tech:** React.js • FastAPI • PostgreSQL • SQLAlchemy • Recharts
